# OCR Text Extractor (Proof of Concept)

This is a simple OCR web application built using Python and Flask.
It allows users to upload an image and extract text using Tesseract OCR.

## Features
- Image upload
- Text extraction using OCR
- Simple web interface

## Tech Stack
- Python
- Flask
- pytesseract
- Tesseract OCR

## Setup Instructions
1. Install Tesseract OCR
2. Install Python dependencies:
   pip install -r requirements.txt
3. Run:
   python app.py
4. Open browser at:
   http://127.0.0.1:5000
